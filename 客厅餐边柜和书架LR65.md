# 客厅餐边柜和书架 LR65

用于把当前客厅效果图中的木纹部分替换为 `Cleaf / 可丽芙 LR65 PORONOCE`。

## 项目资产

- 原图：`11客厅-新1.jpg`
- 原图尺寸：`3840 x 2160`
- 图像类型：客厅柜墙正视角室内效果图
- 任务类型：保留原空间结构的局部材质替换

## 推荐执行方式

- 首选模型：`gpt-image-2`
- 兼容回退：`gpt-image-1.5`
- 推荐模式：`edit`
- 推荐通道：有内置生图工具时优先直接做会话内 edit；只有在用户明确要求 API / CLI 落地时才走本地请求脚本
- 建议出图比例：保持原图 `16:9`
- 中间确认稿：`1536 x 1024`
- 终稿：尽量保持高清横图，并保留原始构图

说明：

- 这个任务的优先级是“保留原空间结构的材质替换”，不是重生新空间。
- 因此优先使用 edit 语义，并把原图与 LR65 实拍一起作为输入。
- `gpt-image-2` 作为优先模型，`gpt-image-1.5` 只作为兼容回退。

推荐顺序：

1. 先做局部改图，分别确认左侧咖啡区、中间格栅区、右侧开放格的 LR65 表现是否稳定。
2. 局部效果满意后，再做整图合并版。
3. 如果整图一次替换出现偏黄、偏红、纹理变粗或误改白色柜门，回退到局部编辑流程。

## 材料定义

- 品牌：`Cleaf / 可丽芙`
- 型号：`LR65`
- 表面：`PORONOCE`
- 视觉：暖浅驼米棕板感、细密直纹、低对比、哑面

英文材料锚点：

```text
Cleaf LR65 Poronoce, a slightly deeper warm camel-beige board finish with a grounded light brown-beige base, very fine dense straight vertical grain, low-contrast variation, a soft satin-matte panel surface with a subtle board sheen, warmer and more grounded, never bleached, pink, grayish, or overly yellow
```

视觉近似色锚点：

- 高光：`#D7BEA4`
- 基础：`#C6A98D`
- 木纹：`#B29173`
- 深纹：`#947659`

## 全局约束

所有 prompt 默认附带以下约束：

- keep the original room geometry, camera angle, lens perspective, daylight direction, and cabinet proportions
- keep all white cabinet doors unchanged
- keep all marble surfaces unchanged
- keep all objects, decor, pendant light, floor, ceiling, walls, and balcony laundry area unchanged
- preserve clean joinery lines, panel gaps, shadow relationships, and realistic material scale
- do not add furniture, do not restyle the space, do not change any non-wood material
- avoid pale washed oak, yellow oak, orange oak, red oak, pink cast, gray-washed oak, walnut tone, oversized mountain grain, rustic knots, glossy reflections

## OpenAI API 落地模板

以下模板用于把本文件里的 prompt 直接转成请求。

优先建议：

1. 单张原图直接改材质：优先 `Image API / images.edits`
2. 需要连续回修、逐轮细调：优先 `Responses API`
3. 优先质量和材质控制：模型用 `gpt-image-2`
4. 需要兼容旧链路时：模型用 `gpt-image-1.5`

### 方案 A：Image API 单次编辑

适合：

- 直接拿 `11客厅-新1.jpg` 做一次局部或整图替换
- 你已经有最终 prompt，不需要多轮对话

`curl` 示例：

```bash
curl -s https://api.openai.com/v1/images/edits \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -F "model=gpt-image-2" \
  -F "image[]=@11客厅-新1.jpg" \
  -F "size=1536x1024" \
  -F "quality=high" \
  -F "output_format=png" \
  -F 'prompt=Edit this interior rendering.

Goal:
Change all visible wood-grain cabinetry parts in the image to Cleaf LR65 Poronoce.

Material reference:
Cleaf LR65 Poronoce, a warm light oak board finish with a light camel-beige wood tone, fine dense straight vertical grain, gentle low-contrast variation, soft matte panel surface.

Change only these wood-grain areas:
- the wood cabinetry around the coffee station on the left
- the vertical wood slatted panel near the center-left
- the small lower wood cabinet below that slatted panel
- the wood frame, shelves, and lower drawer fronts of the open shelving unit on the right side of the main cabinet wall

Keep unchanged:
- room geometry
- camera angle and perspective
- all white cabinet doors
- marble back panels
- countertop objects and decor
- floor, ceiling, walls, lighting, balcony laundry area
- cabinet proportions, panel gaps, and handle-free detailing

Material constraints:
- use LR65 as a warm light oak board with fine dense straight grain
- keep the wood tone light camel-beige, slightly warm, not bleached, not gray-washed, not yellow, not orange, not red, not pink
- keep a realistic matte finish
- preserve stable straight grain direction and realistic low-contrast board texture scale
- do not turn the wood into heavy mountain grain, generic pale oak, or dark walnut
- do not alter any non-wood parts'
```

如果要切到兼容回退模型，只把上面这行改成：

```text
-F "model=gpt-image-1.5"
```

建议参数：

- 中间确认稿：`size=1536x1024`, `quality=medium`
- 最终稿：`size=1536x1024` 或更高横图尺寸, `quality=high`
- 如果只做局部试色：仍可用整张原图，但先换成局部 prompt

### 方案 B：Image API 遮罩局部编辑

适合：

- 你希望只允许模型改特定木纹区域
- 你担心整图编辑时误改白色柜门、石材或摆件

做法：

1. 先按原图尺寸做一张遮罩图
2. 遮罩只覆盖木纹区域
3. 原图和 mask 尺寸必须一致
4. mask 需要 alpha 通道

`curl` 示例：

```bash
curl -s https://api.openai.com/v1/images/edits \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -F "model=gpt-image-2" \
  -F "image[]=@11客厅-新1.jpg" \
  -F "mask=@11客厅-LR65-mask.png" \
  -F "size=1536x1024" \
  -F "quality=high" \
  -F "output_format=png" \
  -F 'prompt=Edit this interior rendering. Change only the masked wood-grain cabinetry areas to Cleaf LR65 Poronoce. Keep all white cabinet doors, marble panels, decor objects, room geometry, perspective, and lighting unchanged. Use a warm light oak board finish with a light camel-beige matte tone, fine dense straight grain, gentle low-contrast variation, not bleached, not gray-washed, not yellow, not orange, not red, not pink, and not dark walnut.'
```

### 方案 C：Responses API 多轮回修

适合：

- 第一轮先出基础结果
- 第二轮继续压色偏、修纹理、修误改区域
- 想复用上一轮结果，而不是每次重新传 prompt

JavaScript 示例：

```javascript
import fs from "fs";
import OpenAI from "openai";

const client = new OpenAI();
const imageBase64 = fs.readFileSync("11客厅-新1.jpg", "base64");

const first = await client.responses.create({
  model: "gpt-5",
  input: [
    {
      role: "user",
      content: [
        {
          type: "input_text",
          text: `Edit this interior rendering.
Change all visible wood-grain cabinetry parts in the image to Cleaf LR65 Poronoce.
Keep the room geometry, original camera angle, white cabinet doors, marble panels, decor objects, lighting, floor, walls, and balcony area unchanged.
Use fine dense straight grain, a warm light camel-beige matte board tone, subtle low-contrast variation, not bleached, not gray-washed, not yellow, not orange, not red, not pink, and not dark walnut.`
        },
        {
          type: "input_image",
          image_url: `data:image/jpeg;base64,${imageBase64}`
        }
      ]
    }
  ],
  tools: [
    {
      type: "image_generation",
      action: "edit",
      size: "1536x1024",
      quality: "high",
      format: "png"
    }
  ],
  tool_choice: { type: "image_generation" }
});

const second = await client.responses.create({
  model: "gpt-5",
  previous_response_id: first.id,
  input: `Refine the current edited image. Match the LR65 real sample more closely. Keep the wood tone slightly deeper warm light brown-beige rather than pale washed oak. Reduce any yellow, orange, reddish, pink, or gray-washed cast. Keep the grain fine, straight, dense, low-contrast, and matte. Do not change any white cabinet surfaces, marble surfaces, decor objects, or room geometry.`,
  tools: [
    {
      type: "image_generation",
      action: "edit",
      size: "1536x1024",
      quality: "high",
      format: "png"
    }
  ],
  tool_choice: { type: "image_generation" }
});
```

说明：

- `Responses API` 适合做连续回修，因为可以直接用 `previous_response_id`
- 图片编辑工具可显式设置 `action: "edit"`
- 如果要强制触发图片工具，可加 `tool_choice: { type: "image_generation" }`

## 本项目推荐调用策略

如果你现在就要落地，建议按下面顺序：

1. 先用 `Image API` 跑 `Prompt 1 / 2 / 3` 的局部版本做试色
2. 局部稳定后，再用 `Image API` 跑整图合并版
3. 如果第一轮整图只差一点，就切到 `Responses API` 用二次修正 prompt 连续回修
4. 如果整图经常误改周边材质，就补做 `mask`，切到遮罩局部编辑
