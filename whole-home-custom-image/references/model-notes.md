# Model Notes

用于记录这个 skill 的模型偏好，避免后续维护时误把“主对话模型”和“图像生成模型”混为一谈。

## 推荐

- Key 选择：
  - 普通请求读取顺序：环境变量 `OPENAI_API_KEY` -> 仓库 `.env` -> `~/.codex/auth.json`
  - 图片生成或改图优先使用 `OPENAI_IMAGE_API_KEY`
  - 未配置 `OPENAI_IMAGE_API_KEY` 时回退到普通 `OPENAI_API_KEY`

- 直接走 Images API：
  - 首选 `gpt-image-2-3x2-4k`
  - 稳定兼容可用 `gpt-image-1`
  - 快速草图可用 `gpt-image-1-mini`

- 走 Responses API / `image_generation` 工具：
  - 可直接使用 `OPENAI_IMAGE_MODEL`
  - 未配置时，额外回退读取 `~/.codex/config.toml` 的 `image_model` 或 `OPENAI_IMAGE_MODEL`
  - 也可用当前可用的 GPT-5 系列主模型先整理指令，再调用图像工具
  - 对于全屋定制改图，优先使用编辑语义而不是纯生成语义

## 原因

- 全屋定制改图依赖局部编辑、材质稳定性、结构保留和细节遵循。
- 这类任务比“纯创意出图”更需要严格执行保留项和修改项。
- 因此默认优先更强的图像编辑模型，而不是只追求低成本。

## 材质校色经验

- 如果用户给了板材实拍，优先用实拍校色，不要只依赖型号名和文字锚点。
- 对木纹板，模型最容易退化成 generic light oak；需要明确压住偏黄、偏红、偏灰白、偏粉和大山纹。
- 当用户连续反馈“不像某个板材”时，下一轮应明确指出偏差维度，比如“更深一点”“去粉感”“纹路更直、更低对比”，不要原样重复上一轮描述。
- 对定制板材，目标通常不是“更像天然木”，而是“更像板材饰面”：细直纹、低对比、哑光、干净、克制。
- 对 `Cleaf LR65`，当前两张实拍共同指向的特征应固定为：
  - 偏暖、略深、略棕的驼棕米色，不漂白，不灰白，不粉
  - 极细密直纹，纹路方向稳定、连续，不能做成粗山纹或花纹
  - 对比度低到中低，但不能糊成纯色平板
  - 表面是 soft satin-matte，带轻微板材光泽，不是死哑光
- 如果出图结果“远看像浅木，近看像普通浅橡木”，说明仍然失败；需要继续往“更深一点、更暖一点、更棕一点、更细一点、更有板材光泽一点”收敛。

## 执行纪律

- 如果 `~/.codex/config.toml` 已配置图片 provider 的 `base_url`，图片调用默认应走该地址，不要再硬编码回 `api.openai.com`。
- 用户给了绝对路径时，以该路径为准；先验证文件存在，再开始改图，不要猜近似文件名。
- “配置已跑通”和“图片已生成成功”必须分开表述；只有图像文件已经落盘，才能对用户说生成完成。
